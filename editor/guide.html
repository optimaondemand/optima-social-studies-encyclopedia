Encyclopedia Editor Guide

How to get set up and start editing. You do not need to install anything. You only need a web browser and a GitHub account.

Just want to look?

On the sign-in screen, choose Just look around (read-only). You can browse every lesson and entry without an account. Nothing can be saved in this mode.

Set up to edit (one time, about five minutes)

  1. Get write access. Your GitHub account must have write access to the repository optimaondemand/optima-social-studies-encyclopedia. If you do not have it, ask the repository owner to add you as a collaborator, and accept the invitation GitHub emails you.
  2. Create a token. A token is a long password that lets this editor save on your behalf. Open github.com/settings/personal-access-tokens/new and fill it in like this:
    • Token name: anything you will recognize, such as "Encyclopedia editor".
    • Expiration: pick a date. When it passes, make a new token the same way.
    • Resource owner: optimaondemand
    • Repository access: choose Only select repositories, then pick optima-social-studies-encyclopedia.
    • Repository permissions: find Contents and set it to Read and write. Leave everything else alone.
    Press Generate token and copy it right away. GitHub shows it only once.
  3. Sign in. Open the editor, paste the token into the Token box, and press Sign in.
If GitHub says the organization must approve your token, tell the repository owner. They can approve it from the organization's settings. Keep your token private. It stays in your browser and is used only to talk to GitHub.

Finding something to edit

  • Lessons shows every lesson in the library, grouped by topic folder in rough chronological order. Click a folder to open it, and click a lesson to preview it. A green dot means the lesson already has an entry.
  • Entries is the table of entries. You can filter by topic area.
  • + New topic starts an entry that does not exist yet.

Editing and saving

  • Click an entry to open it and write in the editor. Press Enter to split a paragraph and Backspace at the start of a paragraph to join it to the one above. Bold and italic are the only styling an entry allows.
  • Save sends your change to GitHub right away as a commit under your own name. The history shows who changed what and when. You do not need to press a separate Push button.
  • If someone else saved the same entry after you opened it, the editor tells you and asks you to reopen it so you can see their version first. Then make your change again.

What does not work on this page yet

  • Refresh and the lesson re-scan need the project owner's local copy. When lessons change, the lesson list on this page updates only after the owner re-scans and publishes.
  • Lesson changes is a preview. Applying an entry to its lesson does not change the lesson page itself yet.
  • Push to GitHub only explains that your saves are already on GitHub.
